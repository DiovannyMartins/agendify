# Reserva nasce como confirmed

Reservas válidas são criadas como `confirmed`; não existe aprovação manual no fluxo padrão do MVP.

A padronização manual exigiria a profissional responder a cada pedido, o que destrói o benefício central de agendamento 24/7. O trade-off é simples e a reversão é cara do ponto de vista de produto (exigiria mudar o fluxo do cliente e a semântica dos estados). Mantida para o MVP.
